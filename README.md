# Rusher — Portfolio

Single-page portfolio built with [Astro](https://astro.build), statically generated.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) to see it.

Edit the page at `src/pages/index.astro`.

## Build

```bash
npm run build   # type-checks and outputs static site to ./dist
npm run preview # preview the production build locally
```

## Deploy

Static output in `dist/` — deploy to Vercel, Netlify, or any static host.
